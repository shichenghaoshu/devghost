# DevGhost v0.1 Vertical Slice Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build the first runnable DevGhost/GhostBench local-first vertical slice from synthetic source discovery to safe evidence, personalized skill compilation, mock arena scoring, and report generation.

**Architecture:** The repository is a pnpm/Turborepo monorepo with TypeScript packages for contracts, discovery, redaction, evidence, skill compilation, arena, scoring, and reporting. Python services provide the FastAPI/worker skeleton and compatible Pydantic contract models. JSON Schema remains the source of truth for cross-language contracts.

**Tech Stack:** TypeScript, pnpm, Turborepo, Vitest, Commander, Zod, JSON Schema, Python, FastAPI, Pydantic, pytest, Docker Compose, PostgreSQL, Redis, MinIO.

---

## Phase 0: Foundation

1. Create repository metadata, documentation, ADRs, and open-source governance files.
2. Create pnpm workspace, package scripts, TypeScript base config, Vitest config, ESLint config, and Turborepo pipeline.
3. Create Python workspace metadata with uv-compatible `pyproject.toml`.
4. Create Docker Compose with API, worker, PostgreSQL, Redis, and MinIO.
5. Create GitHub Actions CI skeleton and dependency update config.

## Phase 1: Contracts

1. Define JSON Schemas under `datasets/schemas`.
2. Export TypeScript Zod schemas and types from `packages/contracts`.
3. Export compatible Pydantic models from `python/ghostbench-core`.
4. Add schema validation tests and fixture data.

## Phase 2: Discovery and Consent

1. Implement metadata-only source discovery for synthetic, Codex, Claude Code, and Git sources.
2. Implement authorization state transitions without reading content during dry runs.
3. Add denylist and path-safety helpers.
4. Add CLI commands `doctor`, `discover`, and `scan`.

## Phase 3: Security Pipeline

1. Implement secret detection, PII detection, prompt-injection detection, and redaction reports.
2. Ensure no raw secret values appear in reports or logs.
3. Add security tests for high-entropy strings, fake API keys, prompt injection, and path traversal.

## Phase 4: Evidence Pipeline

1. Convert authorized synthetic fixtures into normalized `EvidenceRecord` objects.
2. Deduplicate evidence, resolve stale/conflict items, and create a minimal graph export.
3. Add tests for evidence type handling and aspirational exclusion.

## Phase 5: Skill Compiler

1. Implement deterministic SkillIR compilation.
2. Implement universal, Codex, and Claude Code adapters.
3. Generate a skill package with canonical hash, manifest, provenance map, and redaction report.
4. Add tests for deterministic output and token budget enforcement.

## Phase 6: Public Arena

1. Create four public synthetic tasks.
2. Implement mock agent, score calculation, scorecard, and three MVP conditions.
3. Generate local unverified run manifest and HTML report.
4. Add tests for score weights and report sanitation.

## Phase 7: Web and Share Card

1. Create a minimal Next.js web app skeleton with landing, privacy, methodology, report, leaderboard, task explorer, skill inspector, and share card pages.
2. Generate HTML, SVG, and sanitized share-card data from local runs.

## Phase 8: Server Skeleton

1. Create FastAPI submission/run endpoints and health checks.
2. Implement submission state transitions and mock worker job execution.
3. Add upload safety validation stubs and retention deletion hooks.
4. Keep production authentication, payment, and public leaderboard out of v0.1.
