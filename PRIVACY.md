# Privacy

DevGhost is local-first. Discovery records metadata before content is read.
Content reads require explicit authorization.

v0.1 does not upload:

- raw Codex memories;
- raw Claude Code memories;
- Git diffs or private code;
- local absolute paths;
- environment variables;
- API keys or credentials;
- raw evidence excerpts.

Reports use aliases, hashes, and sanitized counts.
